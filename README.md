# June Shim — Academic Homepage

A minimal personal academic website built with HTML and CSS for GitHub Pages.

## Files
- `index.html`: page content
- `style.css`: visual styles
- `June_Shim_CV.docx`: downloadable CV

## Publish with GitHub Pages
1. Create a **public** repository named `juneshim.github.io` in the GitHub account `juneshim`.
2. Upload all files from this folder to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, select **Deploy from a branch**, branch `main`, folder `/(root)`.
5. Wait a few minutes, then visit `https://juneshim.github.io`.

## Before publishing, verify
- Confirm the official English title of the journal article is reproduced exactly.
- The official English name of the master's department and bachelor's degree.
- The listed degree dates and any training/course status.
- Whether you want your email displayed publicly.
- ORCID profile linked: https://orcid.org/0009-0004-1122-4031.
- Consider replacing the CV DOCX with a PDF once the CV is finalized.
- The public contact email is june.shim@sookmyung.ac.kr.

## Editing
Open `index.html` to edit the text and links. Open `style.css` to adjust the design.
